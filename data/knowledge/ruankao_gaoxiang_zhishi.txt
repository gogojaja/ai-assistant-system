软考高项（信息系统项目管理师）知识总结

==================================================

第一部分：考试介绍

软考高项 = 计算机技术与软件专业技术资格（水平）考试 高级
由人社部 + 工信部联合发证，以考代评，通过即认定副高级工程师职称
每年考一次（上半年5月），2023年启用第四版教材

考试科目：
1. 综合知识（上午9:00-11:30）：75道单选题，75分满分，45分及格
2. 案例分析（下午13:30-15:00）：3道问答题，75分满分，45分及格
3. 论文（下午15:30-17:30）：二选一，75分满分，45分及格
三科必须同时通过，成绩不延续

第二部分：十大管理领域（核心考点）

一、整合管理（整体管理）
7个过程：制定项目章程 → 制定项目管理计划 → 指导和管理项目工作 → 管理项目知识 → 监控项目工作 → 实施整体变更控制 → 结束项目或阶段

二、范围管理
6个过程：规划范围管理 → 收集需求 → 定义范围 → 创建WBS → 确认范围 → 控制范围

三、进度管理（时间管理）
7个过程：规划进度管理 → 定义活动 → 排列活动顺序 → 估算活动资源 → 估算活动持续时间 → 制定进度计划 → 控制进度

关键路径法：项目中时间最长的活动顺序，决定最短工期
总浮动时间为零的活动在关键路径上
自由浮动时间：不延误任何紧后活动最早开始日期的可推迟时间
进度压缩：赶工（增加资源）+ 快速跟进（并行活动）
资源平衡：改变关键路径，延长工期；资源平滑：不改变关键路径和完工日期

四、成本管理
4个过程：规划成本管理 → 估算成本 → 制定预算 → 控制成本

挣值管理（EVM）：
- PV（计划值）：计划完成工作的预算费用
- EV（挣值）：实际完成工作的预算费用
- AC（实际成本）：实际完成工作的实际费用
- SV = EV - PV（进度偏差）
- CV = EV - AC（成本偏差）
- SPI = EV / PV（进度绩效指数）
- CPI = EV / AC（成本绩效指数）

五、质量管理
3个过程：规划质量管理 → 管理质量（质量保证） → 控制质量

六、资源管理（原人力资源管理）
6个过程：规划资源管理 → 估算活动资源 → 获取资源 → 建设团队 → 管理团队 → 控制资源

七、沟通管理
3个过程：规划沟通管理 → 管理沟通 → 监督沟通

八、风险管理
7个过程：规划风险管理 → 识别风险 → 定性风险分析 → 定量风险分析 → 规划风险应对 → 实施风险应对 → 监督风险

九、采购管理
3个过程：规划采购管理 → 实施采购 → 控制采购

十、干系人管理
4个过程：识别干系人 → 规划干系人参与 → 管理干系人参与 → 监督干系人参与

第三部分：五大过程组与47个过程对应

启动过程组（2个）：制定项目章程、识别干系人
规划过程组（24个）：制定项目管理计划、范围管理4个、进度管理6个、成本管理3个、质量管理1个、资源管理2个、沟通管理1个、风险管理6个、采购管理1个、干系人管理1个
执行过程组（8个）：指导和管理项目工作、管理项目知识、质量保证、获取资源、建设团队、管理团队、管理沟通、实施采购、管理干系人参与、实施风险应对
监控过程组（11个）：监控项目工作、控制范围、控制进度、控制成本、控制质量、控制资源、监督沟通、监督风险、控制采购、监督干系人参与、实施整体变更控制
收尾过程组（1个）：结束项目或阶段

第四部分：高频考点

配置管理：
- 配置库：开发库（动态库，开发人员控制）、受控库（主库，包含基线）、产品库（静态库，最终产品）

变更管理流程：
变更申请 → 初审 → 变更方案论证 → CCB审核 → 通知并实施 → 监控实施 → 效果评估 → 变更收尾

合同类型（按范围划分）：
- 项目总承包合同：全过程整合发包给同一卖方
- 项目单项承包合同：分别与不同卖方订立合同
- 项目分包合同：卖方将部分项目再发包给分包方

冲突管理解决办法：
- 撤退/回避：暂时退出（暂时性）
- 缓和/包容：强调一致淡化分歧（暂时性）
- 妥协/调解：双方让步有得有失
- 强迫/命令：一方赢一方输
- 合作/解决问题：最理想结果

确认范围步骤：
确定确认时间 → 识别需要投入 → 确定接受标准和要素 → 确定会议组织步骤 → 组织确认会议

团队发展阶段（塔克曼模型）：
形成 → 震荡 → 规范 → 发挥 → 解散

项目章程内容：
项目目的、可测量目标、高层级需求和描述、整体风险、里程碑进度计划、财务资源、关键干系人、审批要求、退出标准、项目经理职权、发起人信息

干系人分析模型：
权力/利益方格、权力/影响方格、影响/作用方格、凸显模型

风险管理计划内容：
策略、方法论、角色职责、资金、时间、风险类别、干系人风险偏好、概率影响矩阵、报告格式、跟踪

第五部分：第四版教材主要变化

1. IT部分扩展为5章：信息化发展、信息技术发展、信息系统治理、信息系统管理、信息系统工程

3. 增加项目绩效域概念
4. 资源管理 = 原人力资源管理 + 实物资源管理

第六部分：论文写作要点

1. 正文字数不少于2000字（含标点）
2. 项目简介详细描述核心功能和技术语言
3. 积极回应子题目
4. 依据项目实际描述，忌空谈理论
5. 结构完整：开篇点题 → 正文论述 → 结尾总结
6. 包含项目背景、过程应用、遇到问题、解决方案、个人心得
