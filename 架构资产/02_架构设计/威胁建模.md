## 2. STRIDE 威胁分析

| 类别 | 威胁场景 | 受影响组件 | 消减措施 | 验证方式 | 状态 |
|------|----------|------------|----------|----------|------|
| **S 仿冒** | 伪造飞书事件回调，冒充用户下发指令 | callback_server / webhook | 校验飞书事件签名与 APP 凭证；仅信任已配置 APP_ID | security_audit | 生效 |
| **T 篡改** | 回调消息体被中间人篡改 | Flask webhook | 全链路 HTTPS；事件体完整性校验 | security_audit | 生效 |
| **R 抵赖** | 敏感操作（清空记忆/删除日程）无法追溯 | 全链路 | 操作日志分级归档 + 13_安全审计台账留痕 | 日志审计 | 生效 |
| **I 信息泄露** | 对话/记忆明文落盘或上传云端 | chat-assistant 记忆/历史 | AES 加密留存本地；密钥隔离 .env 不入库；禁止迁云端 | security_audit | 生效 |
| **I 信息泄露** | 飞书凭证硬编码或提交仓库 | shared/feishu_api | .env 仅本地、gitignore 管控；密钥脱敏（B 级） | 配置核验 | 生效 |
| **D 拒绝服务** | 模型进程 OOM/卡死导致服务不可用 | 推理后端 | 内存上限 8GB 自动重启；闲置 30min SIGSTOP、请求 SIGCONT | monitor 日志 | 生效 |
| **D 拒绝服务** | 高频回调压垮回调服务 | callback_server | 守护线程 keepalive + 异常自拉起 + 定时备份 | monitor 日志 | 生效 |
| **E 权限提升** | 命令注入（起草/委派/转PPT）越权 | message_handler / document_handler | 输入校验；三角色边界隔离；最小权限运行 | 架构评审 | 生效 |
| **E 权限提升** | 外部文档工具越权访问本机 | external_doc_tools | 仅 HTTP 调用已部署外部服务；本环境不部署 Docker、不持有外部 key | 安全审计 | 生效 |

## 3. 关键风险与处置

1. **凭证泄露（最高优先级）**：飞书 APP_SECRET 与智谱/外部 key 一律外置 `.env`，仓库 `.gitignore` 排除；提交前脱敏（B 级）。
2. **记忆数据泄露**：跨会话记忆与对话历史强制 AES 加密，密钥独立于代码；提供 `clear` 用户自清除入口。
3. **外部依赖边界**：文档处理/PPT 仅通过 HTTP 调用已部署的外部 PPTAgent，本测试环境不运行 Docker、不持有外部凭证，杜绝权限外溢。
4. **降级安全**：云端不可达时仅降级到本地推理，敏感数据不出本机；禁止任何情况下将记忆/对话迁往云端。
